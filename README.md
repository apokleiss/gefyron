# Gefyron MVP

A responsive React + TypeScript + Tailwind prototype for a commercial photovoltaic assessment and offer-comparison platform.

## Implemented screens

- Professional public homepage
- Seven-step business solar-assessment questionnaire
- Preliminary assessment results with indicative ranges and disclaimers
- Responsive installer offer-comparison dashboard with three fictional proposals

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. The application uses hash-based routes, so it can also be deployed easily as a static site.

## Production note

All calculations, installer details, extracted bill data and financial values are mock demonstration data. The prototype does not provide a final engineering study, guaranteed savings, legal advice, financial advice or a binding installer recommendation.
